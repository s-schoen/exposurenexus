# Review priorities

Especially watch for not not overengineer the solution:

- Always thing of YAGNI (You Ain't Gonna Need It) as a leading principle.
- We don't have to consider every single edge case. Focus on the core aspects of the feature instead of overcomplicating the code by handling edge cases.
- We don't have to worry about performance. Avoid premature optimization
- Prefer readable code, even if it means sacrificing performance or more lines of code. A human has to read the code to understand it
- Prefer simplicity over elegance
- Prefer simple TypeScript types instead of complex ones
- Add short comments to explain complex logic
